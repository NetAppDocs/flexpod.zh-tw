[[power-requirements]]
== 電力需求

根據安裝「支援資料中心」組態的位置、FlexPod 對「支援資料中心」的電源需求各有不同FlexPod 。

如需所需最大電力的詳細資料、以及其他詳細電力資訊、請參閱本節所列每個硬體元件的技術規格 link:dc-tech-spec_technical_specifications_and_references.html["技術規格與參考資料：硬體元件"]。

有關 Cisco UCS 電源資料的詳細說明，請參閱 https://ucspowercalculator.cisco.com/["Cisco UCS電源計算機"^]。

如需 NetApp 儲存控制器電源資料，請參閱 https://hwu.netapp.com/["NetApp Hardware Universe"^]。在 *Platforms* 下，選擇您要使用的儲存平台（例如 AFF A90），選擇 ONTAP 版本，然後按一下 *Show Results*。電源線資料列於 *Supported Power Cords* 區段。如需尺寸、重量、功率等詳細資訊，請參閱 *Size, Weight, Acoustic, Power* 區段。
