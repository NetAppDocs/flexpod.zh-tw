= 其他需求
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
FlexPod Datacenter 的其他要求包括以下幾點：

* 如果您打算使用 VMware ESXi 作為 Hypervisor，請參閱 link:https://compatibilityguide.broadcom.com/["Broadcom 相容性指南"] 以確認您的硬體和軟體元件是否受支援。
* 對於以 OpenShift 為基礎的部署，請確保您擁有與 OpenShift 相容的必要硬體和軟體元件。如需更多資訊，請參閱 link:https://catalog.redhat.com/en/search["OpenShift 目錄"]。
