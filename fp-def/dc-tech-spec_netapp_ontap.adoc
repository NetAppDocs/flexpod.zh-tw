= NetApp ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
NetApp ONTAP 軟體是在 AFF、ASA、FAS 和 AFX 儲存系統上執行的作業系統。ONTAP 提供易擴充的儲存架構，支援無中斷運作、無中斷升級和敏捷的資料基礎架構。透過 ONTAP One 授權模式，所有企業資料服務均包含在單一套件中，簡化部署與管理，同時提供對進階功能的完整存取。ONTAP 透過 SnapMirror 複寫與災難恢復，以及 SnapCenter 應用程式一致性備份與恢復等技術，提供強大的資料保護。此外，ONTAP 還整合了內建安全功能，包括自主勒索軟體防護和加密，以保護資料免受現代威脅的侵害。ONTAP 還可透過 SnapMirror Cloud 和 S3 型複寫等功能實現無縫混合雲整合，讓資料能夠在地端與雲端環境之間移動，同時維持一致性與控制。

如需 ONTAP 的詳細資訊，請參閱 https://www.netapp.com/ontap-data-management-software/["資料管理軟體ONTAP"^]產品頁面。
