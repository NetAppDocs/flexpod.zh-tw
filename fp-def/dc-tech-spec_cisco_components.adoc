[[cisco-ucs-x-series-modular-system]]
== Cisco UCS X 系列模組化系統

Cisco UCS X 系列模組化系統以 Cisco UCS X9508 伺服器機箱為基礎，機箱設計靈活，符合未來需求的。機箱採用統一的乙太網路架構，配備 Cisco UCS Intelligent Fabric Modules 和 Cisco UCS X-Fabric Technology，可與其他技術相容。機箱頂部後方有兩個至能架構模組，用於將機箱連接到上游的 Cisco UCS 6400、6500 和 UCS 6600 系列 Fabric Interconnects。

有關 Cisco UCS X 系列功能和特性的快速概述，請參閱link:https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-modular-system-aag.html["Cisco UCS X 系列模組化系統概覽"^]。

Cisco UCS X215c M8、Cisco UCS X210c 和 Cisco UCS X410c 運算節點在單一尺寸規格中提供運算密度、儲存容量和可擴充性，因此兼具刀鋒伺服器和機架伺服器的功能。

Cisco UCS X440p PCIe 節點支援透過 Cisco UCS X9416 X-Fabric 模組新增 PCIe Gen 4.0 GPU。Cisco UCS X580p PCIe 節點支援透過 Cisco UCS X9516 X-Fabric 模組新增 PCIe Gen 5.0 GPU。

如需 Cisco UCS X-Series 模組化系統解決方案元件的詳細資訊，請參閱以上各節中每個元件的技術規格。


NOTE: 有關 Cisco UCS X 系列模組化系統的完整技術規格，請參閱以下連結：link:https://www.cisco.com/c/en/us/products/servers-unified-computing/ucs-x-series-modular-system/datasheet-listing.html["Cisco UCS X 系列模組化系統"^]



[[cisco-ucs-x-series-direct-options]]
== Cisco UCS X-Series Direct 選項

Cisco UCS X-Series Direct 是一種新的架構，它將一對 Cisco UCS Fabric Interconnect 9108 100G 與 Cisco UCS X9508 機箱和 Cisco UCS X-Series 運算節點整合在一起，從而提供 UCS X-Series Direct 解決方案。

有關 Cisco UCS X 系列功能和特性的快速概述，請參閱link:https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-direct-aag.html["Cisco UCS X-Series Direct 一覽"^]。

Cisco UCS X 系列 Direct 由下列元件組成：

* Cisco UCS 9108 100G Fabric Interconnect
* Cisco UCS X9508 機箱
* Cisco UCS X 系列運算節點
* 可選組件：
+
** PCIe 節點和 X-Fabric 模組
** 第二台 Cisco UCS X9508 機箱，配備 X-Series 運算節點、Cisco UCS 9108-100G 智慧交換矩陣模組以及最多四台 C-Series 機架式伺服器




有關 Cisco UCS X 系列 Direct 解決方案元件的詳細資訊，請參閱以上各節中每個元件的技術規格。


NOTE: 有關 Cisco UCS X-Series Direct 的完整技術規格，請參閱以下連結： https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-direct-ds.html["Cisco UCS X 系列 Direct 資料表"]。
