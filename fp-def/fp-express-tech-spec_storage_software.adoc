== NetApp ONTAP

NetApp ONTAP 軟體是運作在 AFF、ASA 和 FAS 儲存系統上的作業系統。ONTAP 提供高度可擴充的儲存架構，支援無中斷作業、無中斷升級和敏捷的資料基礎架構。透過 ONTAP One 授權模式，所有企業資料服務均包含在單一套件中，簡化部署與管理，同時提供對進階功能的完整存取。ONTAP 透過 SnapMirror 複寫與災難復原，以及 SnapCenter 應用程式一致性備份與還原等技術，提供強大的資料保護。此外，ONTAP 還整合了內建安全功能，包括自主勒索軟體防護和加密，以保護資料免受現代威脅的侵害。ONTAP 亦支援與混合雲的無縫整合，提供 SnapMirror Cloud 和 S3 型複寫等功能，實現資料在內部部署與雲端環境之間的移動，同時維持一致性與可控性。

有關 ONTAP 的詳細資訊，請參閱 https://docs.netapp.com/us-en/ontap-family/["ONTAP 產品文件"^]。

=== 建議的 ONTAP 功能/組態

FlexPod 透過利用以下特性/組態，實現了我們經過驗證的架構中概述的峰值效能、企業級備援和高可用度：



==== 多路徑和邏輯介面

此架構的設計旨在FlexPod 在在整個運算、網路和儲存堆疊中、元件或連結故障時、提供高可用度。用戶端存取與儲存存取的多重網路路徑、可提供負載平衡與最佳資源使用率。

ONTAP 中的多路徑 I/O 是透過邏輯介面實現的。LIF（邏輯介面）是一個 IP 位址或 WWPN，具有相關的特徵，例如角色、主連接埠、歸屬節點、容錯移轉連接埠清單和防火牆原則。

| NFS / CIFS / S3 | 1. | 2. 


| iSCSI / NVMe Over TCP | 2. | 4.

==== ONTAP Snapshot 快照技術，SnapMirror 以及 SnapCenter

快照是 Volume 的唯讀、時間點映像。建立快照後，作用中檔案系統和快照指向相同的磁碟區塊；因此，快照不使用額外的磁碟空間。隨著時間的推移，該映像佔用的儲存空間極少，且效能負荷也微乎其微，因為它只記錄自上次建立快照以來檔案發生的變更。您可以使用快照來恢復個別檔案或 LUN ，也可以還原整個 Volume 的內容。ONTAP 將快照中的指標資訊與磁碟上的資料進行比較，從而重建遺失或損壞的物件，而無需停機或顯著的效能損失。

SnapMirror 是一種災難恢復技術，旨在從主儲存設備容錯移轉至地理位置遠端站台的次要儲存設備。顧名思義， SnapMirror 會在次要儲存設備中建立工作資料的複本或鏡射，以便在主站台發生災難時，您可以繼續從中提供資料。

SnapCenter 軟體是一個簡單、集中、易擴充的平台，可為混合雲中任何位置的 ONTAP 系統上執行的應用程式、資料庫、主機檔案系統和虛擬機器提供應用程式一致的資料保護。

我們建議客戶將資料保護納入其 FlexPod 架構中，利用 SnapMirror 進行複寫和災難恢復，以及 SnapCenter 進行應用程式一致性備份與恢復等技術。



==== 安全的多租戶

安全多租戶是指在共享的實體儲存設備環境中使用安全的虛擬分區，以便多個不同的租戶共享該實體環境。例如，儲存設備服務供應商可以設定儲存陣列，為三個不同的客戶分別分配陣列的磁碟容量和網路資源。在安全的多租戶環境中，每個客戶只能存取明確分配給該客戶的資源。客戶無法存取其他客戶的資料，甚至不感知其他客戶的存在，也不知道他們共享同一個實體陣列。安全多租戶環境也應提供一種機制，確保沒有單一租戶會佔用過多的共享的效能功能，進而影響其他租戶。

ONTAP 中的多租戶是透過儲存設備虛擬機器（SVM）和 IP Spaces 實現的。

就像在 Hypervisor 上執行的虛擬機器一樣，SVM 是一種抽象化實體資源的邏輯實體。SVM 透過一個或多個網路邏輯介面（LIF），從一個或多個 Volume 提供資料給用戶端與主機。

IPspaces 可讓您設定單一 ONTAP 叢集，以便來自多個管理上分隔之網路網域的用戶端能夠存取，即使這些用戶端使用相同的 IP 位址子網路範圍。這有助於分隔用戶端流量，以保障隱私和安全性。
