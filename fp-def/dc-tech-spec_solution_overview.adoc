= 資料中心技術規格FlexPod
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
該 FlexPod 平台是預先設計、最佳實務做法的資料中心架構，它基於 Cisco Unified Computing System（Cisco UCS）、Cisco Nexus 和 MDS（適用於 FC）系列交換器以及 NetApp 儲存控制器（AFF、ASA、FAS 或 AFX 系統）。

適用於執行各種虛擬化Hypervisor、裸機作業系統和企業工作負載的平台。FlexPod不僅提供基礎組態、還能靈活調整規模及最佳化、以因應多種不同的使用案例和需求。FlexPod


NOTE: 在您訂購完整的 FlexPod 組態之前，請參閱 http://www.netapp.com/us/technology/flexpod["NetApp FlexPod 首頁"^]頁面以取得這些技術規格的最新版本。
